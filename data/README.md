# Dataset Directory

This directory is reserved for storing the **UCI SMS Spam Collection** dataset.

## Dataset Information
- **Dataset Name:** SMS Spam Collection
- **Source:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/228/sms+spam+collection)
- **Description:** A set of 5,574 English, real, uncompressed SMS messages tagged as legitimate (ham) or spam.

## Structure
- Raw datasets downloaded from UCI should be placed in `data/raw/` or `data/SMSSpamCollection`.
- The dataset file is git-ignored as per research best practices (avoiding committing raw data to version control).
